Order Service API Reference

Base URL: http://localhost:30800 | Auth: Bearer token from Keycloak realm org-mind

POST /orders

Create a new order. Requires order-writer role.

{
  "customer_id": "cust-001",
  "items": [
    {"product_id": "prod-A", "quantity": 2, "unit_price": 29.99}
  ]
}
GET /orders/{order_id}

Retrieve a single order by ID.

GET /orders?customer_id=cust-001

List orders. Optional customer_id filter.

PATCH /orders/{order_id}/status

Update order status. Valid values: pending, processing, shipped, delivered, cancelled.

?status=shipped
DELETE /orders/{order_id}

Cancel an order (sets status to cancelled).

GET /metrics

Prometheus metrics endpoint. Scraped automatically by Prometheus.

GET /orders/error-demo

⚠ Intentional error route. Simulates a 500 error with 2-second latency for telemetry demo purposes.

GET /orders/slow-demo

⚠ Intentional latency route. Sleeps for a configurable duration (default 3s). Used to trigger Skywalking slow-trace alerts.

Prometheus Metrics Exposed

  • order_service_requests_total – Counter by method, endpoint, status_code
  • order_service_request_duration_seconds – Histogram of request latency
  • order_service_active_orders – Gauge of in-flight orders
  • order_service_errors_total – Counter of 5xx responses
