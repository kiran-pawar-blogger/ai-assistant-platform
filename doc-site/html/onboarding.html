Developer Onboarding Guide

Prerequisites

  • Docker Desktop or Podman (for KinD/Minikube)
  • KinD or Minikube
  • kubectl v1.28+
  • Python 3.11+
  • Docker Buildx (for building local images)

Quick Start

  1. Clone the repository: git clone https://github.com/org/org-mind.git
  2. Create the cluster: kind create cluster --name org-mind
  3. Run the bootstrap script: bash deploy.sh
  4. Wait for all pods to be Ready: kubectl get pods -n org-mind -w

Getting a Test Token

curl -s -X POST http://localhost:30080/realms/org-mind/protocol/openid-connect/token \
  -d "client_id=order-service" \
  -d "client_secret=order-service-secret-2024" \
  -d "username=testuser" \
  -d "password=Test@1234" \
  -d "grant_type=password" | python -m json.tool

Connecting Claude Desktop to MCP Server

Add the following to your claude_desktop_config.json:

{
  "mcpServers": {
    "org-mind": {
      "url": "http://localhost:30808/mcp",
      "headers": {
        "Authorization": "Bearer <your-token>"
      }
    }
  }
}
